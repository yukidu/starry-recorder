# 繁星 AI 錄音 Starry Recorder

此為繁星生態系獨立錄音 App 的**開發中原始碼**。GitHub 儲存庫公開，但會員錄音與資料必須保持私人且不得放在程式碼倉庫。

**目前狀態：尚未部署、不可對外提供錄音或付費服務。**

產品規格：每堂課最多 10 筆錄音；每筆最多 100 分鐘、單檔 100MB；儲存檔案應為 AAC 編碼的 M4A、16kHz、64kbps；使用獨立 Cloudflare Worker、D1、R2，並以中央 Starry ID 驗證身份。正式上線須完成 AI、音訊處理、原生背景錄音、商店訂閱與安全驗收。

本次建立僅為專案初始化，不代表前端正式建置、雲端部署或 App 商店上架成功。
